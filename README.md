# Medical Assistance

A simple medical assistance system developed using Java, JDBC, MySQL, HTML, CSS and JavaScript.

## Features

- Patient Registration
- Patient Login
- Symptom Selection
- Specialist Recommendation
- Doctor Recommendation
- Doctor Slot Availability
- Appointment Booking
- Appointment Receipt
- My Appointment

## Technologies Used

- HTML
- CSS
- JavaScript
- Java
- JDBC
- MySQL
- XAMPP

## Project Structure

- `index.html` - Frontend
- `script.js` - Frontend functionality
- `style.css` - Styling
- `MedicalServer.java` - Java backend server
- `DatabaseConnection.java` - Database connection
- `medical_assistance.sql` - Database structure and sample data
- `lib/` - MySQL JDBC connector

## How to Run

1. Start Apache and MySQL using XAMPP.
2. Import `medical_assistance.sql` into MySQL/phpMyAdmin.
3. Make sure the MySQL JDBC connector is available.
4. Run `MedicalServer.java`.
5. Open `index.html` in a browser.
